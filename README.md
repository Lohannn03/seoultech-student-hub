# SeoulTech Student Hub

> 서울과학기술대학교 학생들을 위한 스마트 대학생활 통합 관리 웹 플랫폼

**개발 상태:** 4주차 데이터 저장 및 API 연동 기능 구현 단계 (개발 진행 중)  
**프로젝트 유형:** 웹프로그래밍 개인 프로젝트  
**웹사이트:** https://lohannn03.github.io/seoultech-student-hub/  
**GitHub:** https://github.com/Lohannn03/seoultech-student-hub

## 1. 프로젝트 소개

**SeoulTech Student Hub**는 학생들이 시간표, 과제와 제출 기한, 학습 기록 등을 하나의 웹페이지에서 관리할 수 있도록 기획한 통합 학습 관리 프로젝트입니다.

서로 다른 곳에 흩어져 있는 학업 정보를 한 화면에서 확인할 수 있는 대시보드를 제공하고, HTML5, CSS3, JavaScript 및 DOM API를 활용해 웹프로그래밍 수업에서 학습한 내용을 실제 서비스 형태로 구현하는 것을 목표로 합니다.

현재는 **시간표·과제 관리, localStorage 저장, 학습 시간 기록, 서울 날씨 API 연동** 기능의 코드를 구현한 상태입니다. 그 외 일부 기능은 화면 구성만 완료되었거나 향후 개발 예정입니다.

## 2. 프로젝트 목표

- 대시보드에서 주요 학업 정보를 한눈에 확인할 수 있는 UI 구성
- 사용자가 시간표와 과제를 직접 등록하고 관리하는 기능 구현
- JavaScript의 DOM 조작과 이벤트 처리 기법 적용
- 반응형 레이아웃을 이용하여 다양한 화면 크기에 대응
- Web Storage와 공개 API를 활용한 데이터 저장 및 외부 정보 연동

## 4. 사용 기술

### 현재 적용 기술

- **HTML5:** 시맨틱 태그를 이용한 웹페이지 구조 작성
- **CSS3:** 레이아웃, 컴포넌트 스타일 및 반응형 디자인
- **JavaScript (Vanilla JS):** 입력 데이터 및 사용자 이벤트 처리
- **DOM API:** 요소 생성, 내용 갱신, 이벤트 리스너 등록
- **Web Storage / JSON:** localStorage에 사용자 입력 저장 및 복원
- **Fetch API:** Open-Meteo의 서울 현재 날씨 JSON 응답 조회
- **Git / GitHub:** 소스 코드 버전 관리
- **GitHub Pages:** 정적 웹사이트 배포

### 향후 도입 검토 기술

- **노트 관리 기능:** 강의별 텍스트 노트의 입력·조회·삭제
- **기능별 테스트 및 개선:** 주요 사용 시나리오 및 접근성 점검
- **선택적 추가 기능:** 데이터 내보내기, 상세 통계 등

## 7. 기본 사용 방법

### 시간표 관리

1. **시간표 관리** 영역에서 과목명을 입력합니다.
2. 수업 요일, 시작 시간 및 종료 시간을 선택합니다.
3. **수업 추가** 버튼을 클릭합니다.
4. 등록된 시간표를 확인하고 필요하면 **삭제** 버튼을 사용합니다.

같은 요일에 수업 시간이 중복되거나 종료 시간이 시작 시간보다 빠르거나 같은 경우에는 등록할 수 없도록 입력값 검증 로직을 적용하였습니다.

### 과제 관리

1. **과제 관리** 영역에서 과제명과 과목명을 입력합니다.
2. 제출 마감일을 선택합니다.
3. **과제 추가** 버튼을 클릭합니다.
4. 등록된 과제에 대해 **완료**, **취소** 또는 **삭제** 기능을 사용할 수 있습니다.

완료하지 않은 과제의 개수는 대시보드에 반영됩니다.

### 학습 기록 관리

1. **학습 기록** 영역에서 과목명, 학습 날짜 및 학습 시간(분)을 입력합니다.
2. **학습 기록 추가**를 선택하면 목록과 주간 학습 시간에 반영됩니다.
3. 기록을 삭제하면 주간 합계와 막대 표시가 갱신됩니다.
4. 날짜 기준 주간 합산 범위는 월요일부터 일요일까지입니다.

### 서울 날씨 정보

캠퍼스 정보 영역에서 Open-Meteo 공개 API를 활용하여 서울 좌표 기준의 현재 기온, 습도, 날씨 코드를 조회합니다. **날씨 새로고침** 버튼으로 다시 요청할 수 있습니다. 네트워크나 API 오류가 발생할 경우 오류 안내 문구가 표시됩니다.

### 브라우저 데이터 저장

시간표, 과제, 학습 기록을 변경할 때 JavaScript에서 `JSON.stringify()`로 데이터를 직렬화해 `localStorage`에 기록합니다. 페이지를 다시 열면 `JSON.parse()`로 데이터를 읽고 유효성을 검사한 후 화면을 갱신합니다. 이 저장 방식은 서버나 다른 기기와 동기화되지 않습니다.

## 10. 현재 한계

- 데이터는 브라우저별 localStorage에만 저장되며 서버·기기간 동기화되지 않습니다.
- 시간표와 과제 기능은 기본적인 등록·조회·상태 변경·삭제 중심으로 구성되어 있습니다. 기존 항목을 직접 수정하는 기능은 구현하지 않았습니다.
- 학습 기록 및 주간 막대 표시는 기본 수준으로 구현하였으며, 강의 자료 관리와 상세 분석 기능은 미구현입니다.
- 날씨 API는 서울 고정 좌표를 이용하므로 사용자의 실제 위치 기반 날씨 정보는 아닙니다.
- 사용자별 계정, 서버 데이터베이스 및 인증 기능은 구현되지 않았습니다.
- 브라우저별·기기별 실제 동작 및 API 응답 테스트 결과는 아직 별도 확인이 필요합니다.
