# SeoulTech Student Hub

> 서울과학기술대학교 학생들을 위한 스마트 대학생활 통합 관리 웹 플랫폼

**개발 상태:** 3주차 기능 구현 단계 (개발 진행 중)  
**프로젝트 유형:** 웹프로그래밍 개인 프로젝트  
**웹사이트:** https://lohannn03.github.io/seoultech-student-hub/  
**GitHub:** https://github.com/Lohannn03/seoultech-student-hub

---

## 1. 프로젝트 소개

**SeoulTech Student Hub**는 학생들이 시간표, 과제와 제출 기한, 학습 기록 등을 하나의 웹페이지에서 관리할 수 있도록 기획한 통합 학습 관리 프로젝트입니다.

서로 다른 곳에 흩어져 있는 학업 정보를 한 화면에서 확인할 수 있는 대시보드를 제공하고, HTML5, CSS3, JavaScript 및 DOM API를 활용해 웹프로그래밍 수업에서 학습한 내용을 실제 서비스 형태로 구현하는 것을 목표로 합니다.

현재는 **시간표 및 과제 관리의 기본적인 상호작용 기능**까지 개발한 상태입니다. 그 외 일부 기능은 화면 구성만 완료되었거나 향후 개발 예정입니다.

## 2. 프로젝트 목표

- 대시보드에서 주요 학업 정보를 한눈에 확인할 수 있는 UI 구성
- 사용자가 시간표와 과제를 직접 등록하고 관리하는 기능 구현
- JavaScript의 DOM 조작과 이벤트 처리 기법 적용
- 반응형 레이아웃을 이용하여 다양한 화면 크기에 대응
- 향후 Web Storage 및 공개 API를 활용하여 기능 확장

## 4. 사용 기술

### 현재 적용 기술

- **HTML5:** 시맨틱 태그를 이용한 웹페이지 구조 작성
- **CSS3:** 레이아웃, 컴포넌트 스타일 및 반응형 디자인
- **JavaScript (Vanilla JS):** 입력 데이터 및 사용자 이벤트 처리
- **DOM API:** 요소 생성, 내용 갱신, 이벤트 리스너 등록
- **Git / GitHub:** 소스 코드 버전 관리
- **GitHub Pages:** 정적 웹사이트 배포

### 향후 도입 검토 기술

- **Web Storage (localStorage):** 사용자 데이터의 브라우저 내 저장
- **JSON:** 저장 데이터의 직렬화 및 역직렬화
- **Fetch API:** 외부 API 요청 및 응답 처리
- **공개 API:** 캠퍼스 생활 관련 외부 정보 연동

향후 도입 검토 기술은 현재 적용된 기능이 아닙니다.

## 5. 프로젝트 구조

```text
seoultech-student-hub/
├── index.html
├── css/
│   ├── reset.css
│   ├── variables.css
│   ├── layout.css
│   ├── components.css
│   ├── dashboard.css
│   └── responsive.css
├── js/
│   └── app.js
└── README.md
```

| 파일 | 역할 |
| --- | --- |
| `index.html` | 대시보드 화면 및 입력 폼 구성 |
| `css/reset.css` | 기본 브라우저 스타일 초기화 |
| `css/variables.css` | 색상, 글꼴, 크기 등 공통 CSS 변수 |
| `css/layout.css` | 사이드바 및 메인 화면 레이아웃 |
| `css/components.css` | 공통 UI 컴포넌트 스타일 |
| `css/dashboard.css` | 대시보드 카드, 입력 폼 및 목록 스타일 |
| `css/responsive.css` | 화면 크기별 반응형 스타일 |
| `js/app.js` | 내비게이션, 시간표 및 과제 관리 로직 |

## 6. 실행 방법

### 온라인 실행

다음 주소에서 웹사이트를 확인할 수 있습니다.

**https://lohannn03.github.io/seoultech-student-hub/**

### 로컬 실행

1. 프로젝트를 복제합니다.

   ```bash
   git clone https://github.com/Lohannn03/seoultech-student-hub.git
   ```

2. 프로젝트 디렉터리로 이동합니다.

   ```bash
   cd seoultech-student-hub
   ```

3. `index.html`을 웹 브라우저에서 열어 화면을 확인합니다.

현재 구현된 기능에는 별도의 서버나 패키지 설치가 필요하지 않습니다.

## 7. 기본 사용 방법

### 시간표 관리

1. **시간표 관리** 영역에서 과목명을 입력합니다.
2. 수업 요일, 시작 시간 및 종료 시간을 선택합니다.
3. **수업 추가** 버튼을 클릭합니다.
4. 등록된 시간표를 확인하고 필요하면 **삭제** 버튼을 사용합니다.

같은 요일에 수업 시간이 중복되거나 종료 시간이 시작 시간보다 빠르거나 같은 경우에는 등록할 수 없도록 입력값 검증 로직을 적용하였습니다.

### 과제 관리

1. **과제 관리** 영역에서 과제명과 과목명을 입력합니다.
2. 제출 마감일을 선택합니다.
3. **과제 추가** 버튼을 클릭합니다.
4. 등록된 과제에 대해 **완료**, **취소** 또는 **삭제** 기능을 사용할 수 있습니다.

완료하지 않은 과제의 개수는 대시보드에 반영됩니다.

## 10. 현재 한계

- 시간표 및 과제 데이터가 메모리에만 저장되므로 새로고침 시 초기화됩니다.
- 시간표와 과제 기능은 기본적인 등록·조회·상태 변경·삭제 중심으로 구성되어 있습니다. 기존 항목을 직접 수정하는 기능은 구현하지 않았습니다.
- 학습 기록, 강의 자료, 통계 및 캠퍼스 정보는 아직 실제 데이터 관리 기능이 없습니다.
- 사용자별 계정, 서버 데이터베이스 및 인증 기능은 구현되지 않았습니다.
- 브라우저별·기기별 실제 동작 테스트 결과는 별도로 확인이 필요합니다.
